This is a transport (Vehicle) reservation system for YWAM.

This is a Django project.
It is convert from a 2010 Classic PHP project found in the old directory.
It uses Unfold Admin for easy styling and adaptation.
HTMX for minimal JS coding and easy interaction from generated html.
Bootstrap for a straightforward UI.

The development setup is with docker compose.

Use `docker compose web python manage.py ...' to run Django commands.

Secrets are stored in '.env'.
